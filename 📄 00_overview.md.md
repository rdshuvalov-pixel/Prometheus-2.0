# Product Overview

## Цель
Создать систему автоматизированного поиска вакансий Product Manager с:
- фильтрацией
- скорингом
- генерацией откликов
- прозрачным объяснением решений

## Основной принцип

LLM = смысл и текст  
Code = логика и контроль  
DB = источник правды  

## Anti-goals
- Нет автономных "агентов, которые сами всё делают"
- Нет принятия решений LLM без валидации
- Нет скрытой логики (всё объясняется)

## Output системы
- список вакансий ≥50 score
- объяснение по каждой вакансии
- cover letters
- pipeline статусов
