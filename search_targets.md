# Search Targets — обновлённый список целей для поиска

## Источник обновления

- Основа: объединённый список компаний и актуализированных ссылок на места для отклика.
- Главная ссылка для обхода: `best_apply_url`.
- Разбиение по Tier основано на качестве ссылки: прямая career/jobs/platform-ссылка → Tier 1; нестандартная hiring-страница или LinkedIn fallback → Tier 2; официальный сайт без явной career page → Tier 3.

## Правила обхода

- **Tier 1 (прямые career/jobs pages):** агент обязан посетить каждую ссылку напрямую. Пропуск недопустим. Если ссылка недоступна — зафиксировать в шапке отчёта и продолжить.
- **Tier 2 (нестандартные hiring pages / fallback):** агент обязан посетить каждую ссылку напрямую. Если это LinkedIn/job-board/company profile — проверить открытые вакансии и страницу компании.
- **Tier 3 (официальные сайты / слабые fallback):** агент обязан посетить ссылку, найти раздел Careers/Jobs/Team/Contact/LinkedIn и зафиксировать, есть ли место для отклика.
- **Tier 4 (job boards):** поиск по запросу `"Product Manager" OR "Product Lead" remote EU` на каждой платформе.
- Порядок обхода: Tier 1 → Tier 2 → Tier 3 → Tier 4.

> Всего компаний: **145**. Tier 1: **109**, Tier 2: **7**, Tier 3: **29**.

## Техническая заметка

- `Tier 1` не означает, что компания точно нанимает прямо сейчас. Это означает, что найден наиболее прямой путь к вакансиям или форме отклика.
- `Tier 2` и `Tier 3` не являются ошибочными ссылками. Это менее прямые, но пригодные входные точки для поиска вакансий.
- Если компания использует внешнюю ATS-платформу, в таблице указан именно лучший найденный URL для обхода, а не обязательно главный домен компании.
